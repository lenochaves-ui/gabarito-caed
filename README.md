# 📋 Leitor de Gabarito CAEd — Croatá/CE

App Android para leitura automática de cartões de resposta CAEd via câmera do celular.

## ⚙️ Como gerar o APK automaticamente

1. Suba este repositório no GitHub
2. Vá na aba **Actions**
3. Clique em **"Build APK"** → **"Run workflow"**
4. Aguarde ~30 minutos
5. Baixe o APK em **Artifacts → GabaritoCAEd-APK**

## 📱 Funcionalidades
- Captura do cartão pela câmera
- Leitura das 52 questões (4 blocos)
- Correção manual de respostas
- Exportação para Excel (.xlsx) no formato oficial
- Histórico de cartões lidos
